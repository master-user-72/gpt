Windows 10/11: запуск Hiddify и отдельного окна ChatGPT

1. Распакуйте весь архив в одну папку.
2. В Hiddify заранее выберите работающий профиль подключения.
   Отключите тихий запуск: главная страница с кнопкой соединения должна быть видна.
   Выберите действие при закрытии окна «Выход», а не «Скрыть в трей».
3. Если программы установлены нестандартно, впишите полные пути к EXE
   в HiddifyPath и ChromePath в начале Start-ChatGPT.ps1.
4. Закройте уже запущенный Hiddify. Дважды нажмите Start-ChatGPT.cmd.
   Запускайте CMD обычным способом; только помощник Hiddify запросит права
   администратора. Не запускайте весь файл от имени администратора.
5. Подтвердите запрос UAC. При запуске не переключайте окно Hiddify,
   пока помощник нажимает кнопку. Поддерживаются русские и английские подписи.
6. После подтверждения статуса соединения откроется ChatGPT в отдельном
   окне Chrome. При закрытии этого окна помощник нажмёт отключение,
   дождётся отключённого статуса и штатно закроет Hiddify.

В отдельном профиле Chrome потребуется войти в ChatGPT заново.
Профиль сохраняется в %LOCALAPPDATA%\HiddifyChatGPT\ChromeProfile.
Обычные окна Chrome скрипт не закрывает. Отключается туннель Hiddify;
обычное подключение компьютера к интернету не отключается.

Автоматизация зависит от того, предоставляет ли установленная версия Hiddify
кнопку через Windows UI Automation. Если нет, сценарий покажет ошибку.
При ошибке отключения/закрытия проверьте Hiddify и завершите его вручную.
Принудительное убийство процесса не используется: оно не гарантирует
восстановления системного прокси и отключения туннеля.
Служебные сообщения сохраняются в %TEMP%\HiddifyChatGPT-<идентификатор>.

Сценарий создан в Linux-среде. Запуск и GUI-автоматизация на Windows
с вашей версией Hiddify пока не проверены.
Исходный код поведения Hiddify проверен по репозиторию
https://github.com/hiddify/hiddify-app (HEAD 98387fe96b1ce5bc01ec463ab2a0d1a6f0c42d2e).

Обновление для диагностики Hiddify 2.5.7:
Перед поиском кнопки запрашивается дерево доступности Windows/Flutter.
Статус соединения распознаётся отдельно от типа элемента управления.
При ошибке рядом со скриптом появится Hiddify-ui-diagnostic.txt.
Он содержит версию, факт отправки нажатия, количество элементов и подписи
соединения; профили, URL, токены и журналы приложения не выгружаются.
Передайте этот файл для диагностики, если повторный запуск не удался.
Это обновление не проверено на Windows; устранение сбоя требует проверки.
