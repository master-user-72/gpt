Windows 10/11 — Hiddify + ChatGPT, версия сценария 4 (Windows x64)

Причина прежнего сбоя установлена по отчёту Hiddify 4.1.1:
UI Automation видит только одну пустую панель. Кнопка не была нажата.
Новый сценарий не использует UI Automation: нажимает указанную вами
кнопку мышью и читает состояние через локальный API ядра Hiddify.
Используется тот же поток CoreInfoListener, что и в самом приложении,
по адресу 127.0.0.1:17078. Буферизованный app.log больше не используется.

Подготовка:
1. Распакуйте все файлы архива в новую папку.
2. В Hiddify выберите работающий профиль, отключите тихий запуск,
   выберите действие при закрытии окна «Выход», закройте диалоги.
3. Завершите Hiddify, включая значок в трее.
4. Запустите Start-ChatGPT.cmd обычным двойным щелчком.
   Только помощник Hiddify запросит права администратора через UAC.

Первый запуск:
Откроется Hiddify. Наведите мышь на центр большой кнопки подключения
на главной странице и нажмите F8 на клавиатуре. Не нажимайте кнопку
мышью самостоятельно. На выбор положения даётся 90 секунд.
Убедитесь, что другие окна/диалоги не перекрывают кнопку.
Координаты сохранятся в Hiddify-button.json рядом со скриптом.

Далее скрипт сам нажмёт кнопку и дождётся состояния STARTED от ядра приложения.
После этого откроется отдельное окно Chrome на https://chatgpt.com.
Закрытие окна запускает отключение, ожидание состояния STOPPED и выход из Hiddify.
Системное подключение к интернету остаётся включённым.
Скрипт не убивает Hiddify принудительно: при неподтверждённом отключении
нужно отключить и закрыть его вручную.

Последующие запуски:
Положение кнопки будет использовано автоматически. Главная страница,
размер окна, масштаб Windows и расположение элементов должны оставаться
такими же, как при первом запуске. Если изменились версия, тема, масштаб
или расположение элементов, удалите Hiddify-button.json и повторите настройку.
При изменении размера окна скрипт откажется нажимать сохранённую точку.

Папка tools обязательна: распакуйте её вместе с остальными файлами.
В ней находится grpcurl.exe 1.9.3 (Windows x64), его лицензия и минимальная
схема протокола статусов. Схема сверена с Hiddify v4.1.1.
SHA-256 дистрибутива проверен по официальной таблице релиза grpcurl:
https://github.com/fullstorydev/grpcurl/releases/tag/v1.9.3
Перед запуском также проверяется SHA-256 сохранённого grpcurl.exe.
API используется только для чтения состояния; подключение/отключение
выполняются нажатием кнопки Hiddify. Журналы, профили и токены не читаются.
Если локальный API недоступен, скрипт покажет ошибку и сохранит её
в Hiddify-ui-diagnostic.txt. Тогда передайте этот файл для диагностики.

Если EXE не найден, укажите его полный путь в HiddifyPath или ChromePath
в начале Start-ChatGPT.ps1. Профиль Chrome сохраняется отдельно в
%LOCALAPPDATA%\HiddifyChatGPT\ChromeProfile; потребуется войти в ChatGPT.
Обычные окна Chrome не закрываются.

Если произошёл сбой, проверьте отключение Hiddify вручную и передайте
Hiddify-ui-diagnostic.txt, созданный рядом со скриптом. Диагностика содержит
режим работы, последний полученный статус ядра, ошибку локального
API и наличие калибровки.

Проверены синтаксис PowerShell, целостность ZIP и запросы всех четырёх
состояний к тестовому gRPC-серверу в Linux-среде, включая таймаут потока.
GUI-запуск на Windows пока не проверен. Схема и адрес API
сверены с исходным кодом Hiddify v4.1.1:
https://github.com/hiddify/hiddify-app/tree/abbd671bf6bf05195acd4158c714bff267cada8f
